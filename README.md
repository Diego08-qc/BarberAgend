
# BarberAgend

Web application for managing barbershop appointments, services and barbers.

## About the project

BarberAgend is a web application designed to simplify appointment management for barbershops.

Customers can explore available services, select a barber and request an appointment through a public interface.

The application also includes appointment management and local data persistence.

## Features

- Dynamic service catalog.
- Dynamic barber catalog.
- Appointment registration.
- Form validation.
- Automatic appointment confirmation.
- Barber availability validation.
- Local data persistence using localStorage.
- Responsive interface.

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Vite
- LocalStorage
- Git and GitHub

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd BarberAgend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
